## ✨ 亮点功能

- **🐱 桌面温柔陪伴**：420+ 条小肥咪不重复温柔语录、节日与陪伴纪念日彩蛋、敲键里程碑蹦跳庆祝、靠近自动 60fps 贴边躲避、摸头治愈呼噜声、蓝牙耳机自动佩戴，以及 4 套苹果质感键盘主题（含空格键迷你猫爪印 🐾）。
- **🍅 间隔效应专注计时器**：支持 `25 / 45 / 90` 分钟专注；每隔随机 3～5 分钟温柔响铃（风铃 / 颂钵 / 木鱼 / 轻叮），**小肥咪同步闭眼陪你放空 10 秒巩固记忆**；支持**打字心流智能顺延**、柔和多屏**闭眼休息幕布**（按 Esc 或轻点跳过）、**看网课自动暂停/续播**及**菜单栏实时倒计时**。
- **🎹 11 套真实采样打字音效**：内置樱桃 3000 / 樱桃 3494 / 机械键盘 / 复古打字机 / 水滴冒泡 / 武侠剑气 / 架子敲鼓 + 麻将音 / 圣熊猫 / 羊驼轴 / 静电容 11 套真实采样，支持音量与音调调节、一键试听、零延迟且输密码自动静音。
- **📊 实时键鼠监控统计 & 一键战报**：
  - 点击菜单栏小猫图标即显大字号「今日输入次数」原生卡片；
  - 完整统计面板涵盖**历史累计总览**、**连续专注天数**、**近 20 周热力图**、**近 7 天 / 30 天 / 按月曲线**与常用按键排行；
  - 一键生成高清 **📸 战报图**复制到剪贴板，随时分享。
- **☁️ iCloud 云盘多设备同步**：开启后通过 macOS iCloud 云盘无冲突合并多台 Mac 的敲键与专注统计，并同步偏好设置与自定义外观。
- **⚡ 原生轻量省电**：Apple Silicon 纯原生打包（仅约 3 MB），原生 CoreAudio 零多余后台进程，输密码自动闭眼防偷窥，支持软件内带进度条一键更新。

## 🚀 安装与使用

1. 前往 [**🇨🇳 小肥咪官网**](https://limoest.github.io/xiaofeimi/)（推荐，国内免代理高速下载）或 [GitHub Releases](https://github.com/limoest/xiaofeimi/releases/latest) 下载最新的 `.dmg` 安装包。
2. 双击打开 DMG，将 **小肥咪.app** 拖入「应用程序（Applications）」。
3. 首次启动后，按小肥咪顶部提示前往 **系统设置 → 隐私与安全性 → 输入监控** 勾选 `小肥咪`，即可实时跟手互动。
4. 后续升级只需点击菜单栏小猫 → **偏好设置 → 检查更新**，软件内一键自动下载更新！
