# 小肥咪 (XiaoFeiMi)

一只专属于 macOS（Apple Silicon）的极简 2D 桌面打字小猫伙伴，原型是一只佩戴红绳银平安锁的英短蓝金渐层。

## 特性

- **双形态内置外观**：提供「小肥咪（立耳）」与「小肥咪（证件照）」两种 2D 造型，并支持通过本地 `cats.json` 或本机 MCP 接口自由扩展自定义外观。
- **自然灵动细节**：跟手敲击原生 Mac 键位键盘与鼠标、摸头呼噜声、胸前 999 银平安锁自然阻尼摆动。
- **蓝牙耳机自动佩戴**：开启「耳机 · 蓝牙自动」后，连接蓝牙耳机自动佩戴白色无线耳机，断开自动摘下。
- **久坐喝水提醒**：连续使用电脑 45 分钟后在头顶温柔浮出无打扰小气泡提醒休息与喝水。
- **原生 macOS 体验**：纯 `arm64` 轻量化打包（约 2.4 MB）、Apple SF Symbols 风格极简菜单栏图标、独立可拖拽设置小窗、支持 GitHub Releases 一键检查更新。

## 安装与使用

1. 前往 [Releases](https://github.com/limoest/xiaofeimi/releases/latest) 下载最新的 `小肥咪.dmg`。
2. 双击打开 DMG，将 `小肥咪.app` 拖入「应用程序（Applications）」。
3. 首次启动后，在 macOS **系统设置 → 隐私与安全性 → 输入监控** 中开启 `小肥咪`，即可跟随打字与鼠标实时互动。
