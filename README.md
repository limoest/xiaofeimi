## ✨ 亮点功能

- **🎹 内置 11 套真实采样打字音效**：
  - 经典原声（源自开源项目 [Tickeys](https://github.com/yingDev/Tickeys)）：樱桃 G80-3000 / 樱桃 G80-3494 / 机械键盘 / 复古打字机 / 水滴冒泡 / 武侠剑气 / 架子敲鼓；
  - 客制化轴体实录（源自开源项目 [KeyBeats](https://github.com/YugBhanushali/keyBeats)）：麻将音 NK Cream / 圣熊猫 Holy Panda / 羊驼线性 Alpaca / 静电容 Topre；
  - Web Audio 内存预解码零延迟驱动，支持音量与音调（Pitch）实时调节、一键试听，输密码自动静音。
- **☁️ iCloud 云盘多设备数据同步**：一键开启后自动通过 macOS iCloud 云盘同步多台 Mac 的敲键统计（按设备分片无冲突合并）、偏好设置与自定义猫咪外观。
- **📊 菜单栏大字号统计卡片 + 热力图 + 一键战报图**：
  - 点击菜单栏小猫图标，顶部即展示放大的苹果原生大字号「今日输入次数」统计卡片与键鼠明细；
  - 点开完整统计面板支持 **历史累计总览**、**近 20 周活跃热力图**、**近 7 天 / 30 天 / 按月曲线**与常用按键排行；
  - 点击 **「📸 战报」** 一键生成高清分享卡片并复制到剪贴板，`Cmd+V` 即可粘贴分享。
- **🎨 4 套苹果质感键盘主题**：苹果银白 / 小肥咪奶油蓝 / 深空灰 / 经典黑橙一键切换，带金属高光倒角、键帽微弧立体感、柔光按压与空格键迷你猫爪印 🐾。
- **💬 420+ 条不重复温柔语录 & 敲键里程碑**：涵盖学习专注、夸夸打气、护眼喝水提醒、节日/周末/陪伴纪念日彩蛋，支持「关闭 / 偶尔 / 话痨」三档调节；每日敲满 `500 / 1,000 / 3,000 / 5,000 / 10,000` 键触发开心蹦跳庆祝。
- **🐾 丝滑贴边躲避 & 原生 CoreAudio 省电架构**：靠近自动 60fps 贴边探头、蓝牙耳机连接自动佩戴（零后台子进程）、输密码自动闭眼防偷窥，Apple Silicon 纯原生打包仅约 **3 MB**。

## 🚀 安装与使用

1. 前往 [**🇨🇳 小肥咪官网**](https://limoest.github.io/xiaofeimi/)（推荐，国内免代理高速下载）或 [GitHub Releases](https://github.com/limoest/xiaofeimi/releases/latest) 下载最新的 `.dmg` 安装包。
2. 双击打开 DMG，将 **小肥咪.app** 拖入「应用程序（Applications）」。
3. 首次启动后，按小肥咪顶部提示前往 **系统设置 → 隐私与安全性 → 输入监控** 勾选 `小肥咪`，即可立即跟手互动。
4. 后续升级只需点击菜单栏小猫 → **偏好设置 → 检查更新**，软件内一键自动下载更新！
