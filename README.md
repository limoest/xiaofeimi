## ✨ 亮点功能

- **🐱 桌面温柔陪伴**：420+ 条小肥咪不重复温柔语录、节日与陪伴纪念日彩蛋、敲键里程碑蹦跳庆祝、靠近自动 60fps 贴边躲避、摸头治愈呼噜声、蓝牙耳机自动佩戴，以及 4 套苹果质感键盘主题（含空格键迷你猫爪印 🐾）。
- **🍅 专注时钟 & 伴学小肥咪**：
  - **右键小肥咪**一键打开专注时钟，支持番茄 ToDo 式**自定义学科/内容清单**（自定义名称 + 标签颜色 + 任意时长）；
  - 专注时小肥咪自动**戴上学习眼镜、面前摆开小书**认真伴学；每隔随机 3～5 分钟温柔响铃（风铃 / 颂钵 / 木鱼 / 轻叮）并同步**闭眼陪你放空 10 秒巩固记忆**；
  - 支持**打字心流智能顺延**、柔和多屏**闭眼休息幕布**（按 Esc 或轻点跳过）、**媒体暂停/续播**及**菜单栏实时倒计时**。
- **📈 专注分析 & 实时键鼠统计**：
  - 全新**专注分析**面板：主打**当日(按小时) / 近 7 天 / 近 30 天 / 按月**专注趋势**折线图**，搭配各学科占比**饼状图**、时长排行**条形图**与连续打卡总览；
  - 菜单栏原生大字号「今日输入次数」卡片，完整统计面板涵盖**历史累计**、**近 20 周热力图**、**当日按小时 / 7天 / 30天 / 按月曲线**及一键高清 **📸 战报图**；
  - 贴心采用 **凌晨 04:00 ～ 次日 03:59:59** 为每日统计周期，熬夜学习工作不断档。
- **🎹 11 套真实采样打字音效**：内置樱桃 3000 / 樱桃 3494 / 机械键盘 / 复古打字机 / 水滴冒泡 / 武侠剑气 / 架子敲鼓 + 麻将音 / 圣熊猫 / 羊驼轴 / 静电容 11 套实录音效，点选即刻生效、支持音量与音调调节、零延迟且输密码自动静音。

## 🚀 安装与使用

1. 前往 [**🇨🇳 小肥咪官网**](https://limoest.github.io/xiaofeimi/)（推荐，国内免代理高速下载）或 [GitHub Releases](https://github.com/limoest/xiaofeimi/releases/latest) 下载最新的 `.dmg` 安装包。
2. 双击打开 DMG，将 **小肥咪.app** 拖入「应用程序（Applications）」。
3. 首次启动后，按小肥咪顶部提示前往 **系统设置 → 隐私与安全性 → 输入监控** 勾选 `小肥咪`，即可实时跟手互动。
4. 后续升级只需点击菜单栏小猫 → **偏好设置 → 检查更新**，软件内一键自动下载更新！
