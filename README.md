## ✨ 亮点功能

- **💬 420+ 条不重复温柔语录**：涵盖学习专注、夸夸打气、护眼喝水提醒、节日/周末/陪伴纪念日彩蛋，洗牌抽签一整轮绝不重复；支持「关闭 / 偶尔 / 话痨」三档调节。
- **🎉 敲键里程碑小庆祝**：每日敲满 `500 / 1,000 / 3,000 / 5,000 / 10,000` 键时，小肥咪会原地开心蹦跳并送上专属夸夸气泡。
- **📊 菜单栏实时统计 + 活跃热力图 + 一键战报图**：
  - 点击菜单栏小猫图标直接看今日敲键与鼠标左右键次数；
  - 点开完整统计面板支持 **历史累计总览**、**近 20 周活跃热力图**、**近 7 天 / 30 天 / 按月曲线**与常用按键排行；
  - 点击 **「📸 战报」** 一键生成高清分享卡片并复制到剪贴板，`Cmd+V` 即可粘贴分享。
- **🐾 丝滑贴边躲避 & 趣味互动**：靠近键盘下半区自动 60fps 贴边探头偷看，不挡点击；轻点可召唤趴趴小黄鸭、不倒翁、毛线球，来回撸头有治愈呼噜声。
- **🎧 原生 CoreAudio 省电架构**：
  - 蓝牙耳机连接自动佩戴、断开自动摘下（原生 CoreAudio API，零后台子进程）；
  - 输密码自动闭眼防偷窥；
  - 纯原生 Apple Silicon 打包，体积仅约 **2.5 MB**。
- **🖥️ 原生 macOS 细节体验**：多显示器切换、首次启动权限温柔引导、软件内带实时进度条与网速一键更新、更新后自动弹出精简更新日志。

## 🚀 安装与使用

1. 前往 [**🇨🇳 小肥咪官网**](https://limoest.github.io/xiaofeimi/)（推荐，国内免代理高速下载）或 [GitHub Releases](https://github.com/limoest/xiaofeimi/releases/latest) 下载最新的 `.dmg` 安装包。
2. 双击打开 DMG，将 **小肥咪.app** 拖入「应用程序（Applications）」。
3. 首次启动后，按小肥咪顶部提示前往 **系统设置 → 隐私与安全性 → 输入监控** 勾选 `小肥咪`，即可立即跟手互动。
4. 后续升级只需点击菜单栏小猫 → **偏好设置 → 检查更新**，软件内一键自动下载更新！
